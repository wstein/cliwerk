# Security Policy

## Reporting a Vulnerability

cliwerk is an independent fork of picocli and is not maintained by the picocli project.

Please report vulnerabilities in cliwerk privately via
[GitHub private vulnerability reporting](https://github.com/wstein/cliwerk/security/advisories/new)
for this repository. Do not open a public issue for them.

If the vulnerability also affects upstream picocli releases (`info.picocli:picocli`),
please also report it to the picocli project as described in
[its security policy](https://github.com/remkop/picocli/blob/main/SECURITY.md).

The resolution of any reported security issues will be handled in confidence.
In your report, please note how you would like to be credited for discovering the issue.

## Supported Versions

Only the latest cliwerk release (see [GitHub Releases](https://github.com/wstein/cliwerk/releases)) receives security fixes.

## Why follow this process
Due to the sensitive nature of security bugs, the disclosure process is more constrained than a regular bug.
We appreciate you following these industry accepted guidelines, which gives time for a proper fix and limit the time window of attack.
