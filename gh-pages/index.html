cliwerk

This is a small self-hosted flat Maven repository for cliwerk, an independent fork of picocli by Remko Popma (Apache License 2.0) that adds e.g. fish shell completion and the cliwerk-spec module below.

cliwerk is not affiliated with or endorsed by the picocli project, and its artifacts are not the official info.picocli:picocli releases on Maven Central. Artifacts are published as io.github.wstein:cliwerk; the Java package is still picocli (drop-in replacement).

Usage

repositories {
    maven { url 'https://wstein.github.io/cliwerk/maven' }
}
dependencies {
    implementation 'io.github.wstein:cliwerk:<version>'
}

cliwerk-spec

Build a picocli CommandSpec from JSON or from a small DSL, export any CommandSpec back to JSON, and merge one or more such specs into a host CLI as subcommands — without an annotated Java class. Meant for giving a beautiful, help-and-completion-enabled picocli front end to a third-party tool whose own CLI isn't human-friendly.

  • Module README (DSL grammar, JSON field reference, worked example)
  • JSON Schema for the JSON format (tracks latest; pin an exact release at spec/schema/<version>/command-spec.schema.json, kept permanently)
  • Javadoc
