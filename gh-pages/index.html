cliwerk

A command line parser for Java that keeps the picocli API and adds fish completion, on-demand help sections, and command specs from JSON or a small DSL.

Read the guideAPI, schema, Maven

Use it

repositories {
    maven { url 'https://wstein.github.io/cliwerk/maven' }
}
dependencies {
    implementation 'io.github.wstein:cliwerk:<version>'
}

The artifact is io.github.wstein:cliwerk. The Java package is still picocli, so existing code compiles unchanged. The list of published versions is in maven-metadata.xml.

What cliwerk adds

  • Fish completion

    AutoComplete.fish() generates a completion script for the fish shell.

  • Command specs

    cliwerk-spec builds a CommandSpec from JSON or a DSL, without annotated classes, and writes it back.

  • Help sections

    helpSection on @Option and @ArgGroup prints targeted help, for example for --Xhelp.

  • Spec tool

    cliwerk-spec command line tool: preview, validate, convert, completion, man pages.
