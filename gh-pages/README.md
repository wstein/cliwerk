# gh-pages source

This directory is the source of truth for the site published at <https://wstein.github.io/cliwerk/>.
It is hand-written static HTML and CSS: no generator, no JavaScript, no external requests.

- `index.html`, `guide/index.html`, `reference/index.html`: pages
- `assets/site.css`: the only stylesheet (system fonts, light and dark via `prefers-color-scheme`)

The release workflow (`.github/workflows/release.yml`) copies everything here except this README
onto the `gh-pages` branch, next to the flat Maven repo (`maven/`), generated Javadoc (`apidocs/`)
and the JSON Schema (`spec/schema/`). Those three are generated by the workflow and are not stored here.

On each release the workflow deletes every top-level entry of the `gh-pages` branch except `.git`, `maven`, `apidocs`, `spec` and `CNAME`
before copying these files in, so files added by hand to the branch (for example `.nojekyll`) are removed. Add such files here instead.

Edit these files, not the `gh-pages` branch. To check links locally, serve this directory
(`python3 -m http.server -d gh-pages`); `apidocs/`, `maven/` and `spec/` links only resolve after a release.
