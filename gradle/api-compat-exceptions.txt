# Accepted exceptions to the API compatibility check (task apiCompat, see gradle/api-compat.gradle
# and docs/FORK.adoc, "Compatibility with upstream picocli").
#
# Each class, method or field line excludes that element of package picocli from the comparison with
# upstream picocli; an annotation-element line excludes nothing (see below). Every exception needs a
# justification and a matching entry in the decision log of docs/FORK.adoc; the check does not accept
# a line without justification.
#
# Format:   <class|method|field|annotation-element> <japicmp pattern> | <justification>
# Examples: class  picocli.CommandLine$Foo                         | <why>, see docs/FORK.adoc
#           method picocli.CommandLine$Help#foo(java.lang.String)  | <why>, see docs/FORK.adoc
#           field  picocli.CommandLine#BAR                         | <why>, see docs/FORK.adoc
#
# Kind annotation-element: a method of an annotation type (@interface) of package picocli that cliwerk
# added WITH a default value. japicmp reports it as METHOD_ABSTRACT_ADDED_TO_CLASS (source-incompatible),
# but for users of the annotation it is source- and binary-compatible: existing annotation uses need not
# set it and existing compiled classes keep working. Only code that implements the annotation interface
# itself would break, which is not a supported use. Unlike class/method/field entries, these are not
# excluded from the comparison: the summary script (.github/scripts/api-compat-summary.py) reports them
# as "excepted" and accepts them only for change METHOD_ABSTRACT_ADDED_TO_CLASS on an annotation type.
# One entry per element, no wildcards: a new element WITHOUT a default value is a real break and
# has to stay a finding; a new element with a default needs its own entry here.
# Residual risk: japicmp does not see default values, so it cannot notice if a default is removed later.
# ApiCompatExceptionsTest (src/test/java/picocli) runs in the regular build and fails if an
# annotation-element entry names an element that does not exist or has no default value.

annotation-element picocli.CommandLine$Option#helpSection()         | annotation element with default value: source and binary compatible for users of the annotation
annotation-element picocli.CommandLine$Parameters#helpSection()     | annotation element with default value: source and binary compatible for users of the annotation
annotation-element picocli.CommandLine$ArgGroup#helpSection()       | annotation element with default value: source and binary compatible for users of the annotation
annotation-element picocli.CommandLine$Command#helpSection()        | annotation element with default value: source and binary compatible for users of the annotation
annotation-element picocli.CommandLine$Command#helpSections()       | annotation element with default value: source and binary compatible for users of the annotation
annotation-element picocli.CommandLine$Command#showHelpSectionsNotice() | annotation element with default value: source and binary compatible for users of the annotation
